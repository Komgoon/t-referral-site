Comment utiliser le code de parrainage Tesla

1

Copier le code de parrainage

Cliquez sur le bouton 'Appliquer et commander' en haut de la page pour copier le code de parrainage.

2

Visiter le site web Tesla

Visitez le site web officiel Tesla (tesla.com) et choisissez le véhicule de votre choix.

3

Commander le véhicule

Choisissez le véhicule de votre choix et cliquez sur 'Commander maintenant'.

4

Choisir les options

Choisissez les options de votre choix comme la couleur, les roues et l'intérieur.

5

Vérifier le code de parrainage

Vérifiez sur la page de paiement si le code de parrainage est automatiquement appliqué.

6

Terminer la commande

Toutes les informations saisies et la commande terminée, pour obtenir les avantages de réduction.

💡 Important à savoir

  • Le code de parrainage n'est valable que pour les nouvelles commandes de véhicules.
  • Une fois appliqué, le code de parrainage ne peut pas être modifié.
  • La réduction sera remboursée lors de la livraison du véhicule.

Questions fréquentes

Qu'est-ce que le code de parrainage Tesla ?

Le code de parrainage Tesla est un code que les propriétaires Tesla existants partagent avec les nouveaux acheteurs. En utilisant ce code lors de votre commande, vous bénéficiez d'avantages supplémentaires.

Dois-je saisir le code de parrainage séparément ?

Non, le code de parrainage Tesla est automatiquement appliqué lorsque vous cliquez sur le lien, vous n'avez donc pas besoin de le saisir séparément.

Quelle est la durée de validité du code de parrainage ?

Actuellement, cette promotion est en cours, donc le code peut être utilisé jusqu'à ce qu'il y ait une annonce officielle.

Tout le monde peut-il utiliser le code de parrainage Tesla ?

Oui, le code de parrainage Tesla est une promotion officielle Tesla, donc tout le monde peut utiliser le code.
